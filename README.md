# 🚢 Titanic Data Analysis — Pandas & Matplotlib

This project is a first exploratory data analysis of the **Titanic dataset** using **Python, Pandas, NumPy, and Matplotlib**.

The objective is to explore the dataset, practice data manipulation, and visualize different aspects of passenger survival.

## 🔎 What I explored

The notebook investigates several questions about the Titanic passengers:

* 📊 General exploration of the dataset using `head()` and `describe()`
* 👴 Survival of passengers aged over 60
* 👶 Survival of children under 14
* 📈 Visualization of survivors according to age
* 👩‍🦱👨 Survival comparison between females and males
* ⚰️ Distribution of ages among passengers who did not survive
* 👨‍👩‍👧‍👦 Exploration of passengers sharing the same family name
* 📊 Comparison between survivors and non-survivors within groups sharing the same name
* 🔀 Separation of the dataset into surviving and non-surviving passengers

## 🛠️ Technologies

* **Python**
* **Pandas** — data manipulation and analysis
* **NumPy** — numerical operations
* **Matplotlib** — data visualization
* **Google Colab** — development environment

## 🧠 Pandas concepts practiced

During this analysis, I practiced:

* DataFrame filtering
* Multiple conditions using `&`
* Column selection
* `groupby()`
* Aggregations such as `count()` and `sum()`
* Creating new columns
* `value_counts()`
* Sorting data
* Removing columns with `drop()`

## 📌 Main purpose

This project is part of my learning journey in **Data Analysis and AI**. It focuses on understanding how to explore raw data, formulate questions, manipulate datasets with Pandas, and transform the results into meaningful visualizations.

The analysis is intentionally exploratory and serves as a practical exercise before moving toward more advanced data analysis and machine learning projects.
